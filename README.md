# Simple Game

Code Striker prototype repository.

## Local development

```bash
npm install
npm run dev
```

## Test

```bash
npm test
```

## Build

```bash
npm run build
```

## GitHub Pages

This project is configured for GitHub Pages using Vite `base: '/simple-game/'` and the workflow in `.github/workflows/deploy.yml`.

After the PR is merged into `main`, enable GitHub Pages in repository settings with **Source: GitHub Actions**. The app will be served from:

```text
https://seungwan-woo.github.io/simple-game/
```
